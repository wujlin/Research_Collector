# Richard Sutton：为什么 RL 视角认为 LLM 还不是经验智能

- Video: [Richard Sutton – Father of RL thinks LLMs are a dead end](https://www.youtube.com/watch?v=21EYKqUsPfg)
- Speaker: Richard Sutton
- Format: interview / podcast
- Transcript: [`transcript.md`](../../youtube/transcripts/21EYKqUsPfg-richard-sutton-father-of-rl-thinks-llms-are-a-dead-end/transcript.md)
- Slides: none. 这是一段对谈，不是带 slide deck 的 lecture；笔记完全基于 transcript 组织。

这期访谈的中心问题是：如果从 reinforcement learning 的角度看，当前以 LLM 为中心的 AI 路线到底缺了什么？Sutton 的回答很尖锐：LLM 的核心机制仍然是模仿人类文本，而不是通过行动、反馈和持续经验来理解世界。它可以很强，但它不是他心目中通向一般智能的基本路线。

这篇笔记不把访谈整理成“LLM 对不对”的口水战，而是按 Sutton 的概念链条展开。他真正强调的是四个层次：

1. 智能必须和目标有关。
2. 学习必须来自经验，而不只是训练语料。
3. 世界太大，智能体必须在生命过程中持续学习。
4. 数字智能时代真正的新问题，是经验如何积累、复制、共享和防污染。

## 1. 00:00-05:00：RL 和 LLM 对“智能”的起点不同

访谈一开始，主持人从 LLM 视角提问：如果我们已经能用大规模文本训练出强大的语言模型，那么从 RL 视角看，我们还缺什么？

Sutton 的第一步不是讨论模型架构，而是重新定义智能问题。他说 RL 更接近 basic AI，因为它关心的是一个系统怎样理解自己的世界，并在世界中决定该做什么。这里有两个关键词：`world` 和 `do`。智能不是只在符号空间里生成一个合适回答，而是在环境中行动，并让行动受到后果约束。

这就把 LLM 和 RL 放到了两种不同位置上。

LLM 的基本训练目标是：给定上下文，预测人类文本中下一个 token 可能是什么。它学到的是人类在大量情境下说过什么、写过什么，以及这些表达之间的统计结构。

RL 的基本设定则是：智能体处在环境中，选择行动，观察后果，并根据 reward 或预测误差改变以后如何行动。它学到的不是“人类会怎么说”，而是“我这样做以后世界会怎样变化，以及这种变化对目标意味着什么”。

所以 Sutton 对 LLM 的核心批评不是“它不够大”，也不是“它不会推理”，而是说它的学习闭环没有对准世界。它的预测对象主要是文本续写，而不是行动之后的世界反馈。

## 2. 02:00-07:00：为什么 Sutton 不把 LLM 看作真正的 world model

主持人提出一个常见反驳：如果 LLM 能预测海量互联网文本，它似乎必须内化某种世界模型。否则它怎么能回答问题、解释现象、写代码、推理呢？

Sutton 的回应是区分两种“预测”。

第一种预测是文本预测。模型预测的是：在这个上下文后，一个人可能会说什么。这当然需要大量结构性知识，但它的目标仍然是预测文本分布。

第二种预测是世界预测。智能体预测的是：我采取某个行动之后，世界会发生什么。这个预测可以被现实后果检验。如果预测错了，智能体会产生 surprise，并据此更新自己。

Sutton 认为 LLM 主要处在第一种预测里。它可以回答“用户可能会怎么回应”，但这种回答仍然是另一个文本输出。它没有在正常生命过程中被迫为自己的行动预测承担后果，也不会因为真实世界给出意外反馈而自动更新长期策略。

这里的关键不是“LLM 是否包含关于世界的知识”。它当然包含大量关于世界的知识。关键是：这些知识是不是由一个行动闭环持续校正。Sutton 关心的是后者。

可以把差异写成一条线：

```text
LLM: context -> next token -> human-like continuation
RL agent: state -> action -> consequence -> update
```

如果没有后半条链，Sutton 就不会把它称为真正意义上的 experience-based world model。

## 3. 05:00-10:00：目标、ground truth 和“什么算对”

访谈接着进入更基础的问题：为什么 Sutton 一直强调 goal？

他的逻辑是，智能必须有某种“好坏”的判据。没有目标，就没有更好或更差；没有更好或更差，就没有真正意义上的学习方向。

在 RL 里，这个判据由 reward 或任务目标提供。比如下棋时，赢棋比输棋好；机器人导航时，到达目标比撞墙好；预测世界时，预测正确比预测错误好。因为有判据，系统才能说：这次行动比那次行动更接近目标。

Sutton 认为 LLM 的 next-token prediction 不提供这种意义上的目标。模型预测下一个 token，并不等于它在世界里追求某个目标。token 是训练语料中的对象，不是环境对行动的反馈。模型输出某句话之后，世界发生什么、用户如何改变、任务是否完成，并不是原始 next-token objective 的核心。

这里可以把“ground truth”分成两类。

文本训练里的 ground truth 是：语料里下一个 token 是什么。

经验学习里的 ground truth 是：行动之后世界实际发生了什么，或者目标是否被推进。

Sutton 认为后者才是智能的基础。前者可以训练出强大的语言能力，但它不自动给出“什么行动是好的”这个定义。

这也是他反复反对把 LLM 看作“有目标系统”的原因。next-token prediction 对他来说不是行动目标，而是训练任务。真正的目标必须能进入世界，并让系统根据后果改变行为。

## 4. 10:00-15:00：Bitter Lesson 在这里被重新解释

主持人把话题转到 Sutton 著名的 `The Bitter Lesson`。现在很多人会说：LLM 正是 bitter lesson 的胜利，因为它放弃了手工符号规则，用海量计算和数据学习通用模式。

Sutton 的回答更微妙。他承认 LLM 有 bitter lesson 的一面：它确实用大量计算扩展了学习能力。但他也指出，LLM 仍然严重依赖人类知识，因为它的燃料主要是人类写出的文本、代码和反馈。

这就形成一个张力。

一方面，LLM 是 scalable computation 的成果。

另一方面，LLM 的数据来源仍然是人类经验的外化记录。

Sutton 预计，真正更可扩展的路线会是直接从经验中学习。也就是说，系统不再主要依赖人类把知识写成文本，再让模型模仿；而是让智能体自己在环境中行动、试错、观察、更新。

这也是他为什么不愿意把 LLM 当作通往 experience era 的自然起点。主持人提出一种折中说法：LLM 可以先作为 prior，然后再用经验学习继续训练。Sutton 不完全否认这种可能，但他强调历史上很多路线一开始都可以说“先用人类知识，再加可扩展方法”。问题是，一旦系统和研究共同体锁进人类知识路线，就很容易延缓真正可扩展路线的发展。

所以这里的判断不是简单的“LLM 没用”。Sutton 的判断是：

```text
人类知识可以帮系统起步，
但如果系统的核心学习机制仍然围绕模仿人类知识，
它就可能不是最终最可扩展的路线。
```

## 5. 15:00-23:00：学习不是 training，而是主动经验过程

这一段是访谈中概念冲突最明显的部分。主持人试图用儿童学习类比 LLM 的 training：儿童早期也像是在接受训练，父母和学校会告诉他们该怎么做。

Sutton 反对这个说法。他认为“training”这个词会误导我们。儿童和动物的基本学习过程不是被给定一组输入输出样本，然后拟合目标标签；而是主动尝试、观察结果、调整行为。

他用婴儿学习来说明这一点。婴儿移动眼睛、发出声音、抓东西、探索身体和环境，这些行动并没有一个预先给好的标签告诉他“正确动作是什么”。他是在行动中发现世界结构：我这样动会看到什么，我这样发声会产生什么声音，我这样抓会碰到什么。

这和 LLM 的训练语料有本质差异。LLM 被给定的是人类已经产生的文本序列；婴儿面对的是一个正在被自己行动改变的世界。

主持人进一步提出文化学习和模仿的重要性，比如人类通过模仿长辈学会复杂技能。Sutton 承认模仿存在，也承认文化传递重要。但他把它放在更基础的动物学习之上。线性地说：

```text
基础层：预测和试错控制，所有动物都依赖它。
上层：模仿、语言、文化传递，人类在这层特别强。
```

Sutton 的问题是，当前 AI 讨论常常从上层开始，把语言和文化模仿看成智能本体；而他想从基础层开始，把行动、预测、试错和反馈看成智能本体。

这对理解 LLM 很重要。LLM 学到了大量上层文化材料，但 Sutton 认为它缺少更底层的持续经验机制。

## 6. 23:00-30:00：reward 是任意的，但必须存在

访谈随后问到：如果未来有一个通用的持续学习智能体，它的 reward function 到底是什么？

Sutton 的回答不是给出一个统一目标，而是说 reward 可以是任意的。下棋时 reward 是赢棋；松鼠的 reward 可能和获得坚果、避免伤害有关；动物的一般 reward 可能和痛苦、愉悦、生存、探索有关。对于一般 AI，还可能存在 intrinsic motivation，也就是让系统因为增加对环境的理解而得到内部驱动。

这说明 Sutton 并不是说所有智能都必须共享同一个目标。他强调的是：无论目标是什么，系统必须有一个能让行动被评价的机制。

主持人进一步追问：如果一个 AI 要服务很多人、处理很多任务、在很多实例之间复制，那么它的知识如何共享？

Sutton 在这里提出数字智能相对于生物智能的一个巨大差异。一个孩子成长后学到的东西不能直接复制给另一个孩子；但 AI 可以有许多副本，可以共享参数、记忆或经验。这意味着未来的持续学习系统不必每次从零开始。一个实例在某个环境中学到的东西，理论上可以被迁移给其他实例。

这一步把问题从“一个 agent 怎样学习”推进到“agent population 怎样积累经验”。它和我们之前读 Leibo / Baronchelli 时关心的多智能体、群体学习、文化演化有直接关系：数字智能的文化积累可能比人类更快，因为它可以复制和合并经验，而不是只能通过语言慢慢传递。

## 7. 30:00-35:00：Big world hypothesis：世界太大，不能预先塞进模型

Sutton 接着提出一个很关键的判断：世界太大了。

主持人举了一个现实任务的例子：一个人做创业，最终 reward 可能十年后才出现；但他每天都要吸收客户、公司、市场、人际关系、产品细节等大量上下文。系统如何处理这种长时程、稀疏回报、海量局部信息？

Sutton 的回答是：这正说明智能体必须在具体生命过程中学习。LLM 路线隐含的梦想是，把足够多知识预先塞进模型里，让模型部署时已经知道一切。但真实世界太大，具体情境太多，局部差异太重要。没有任何预训练阶段能覆盖一个 agent 将来遇到的所有客户、公司、地点、偏好和任务。

所以 Sutton 更赞成持续学习，而不是把所有知识都塞进 context window。LLM 视角下，局部信息常常被看作上下文窗口里的内容；RL / continual learning 视角下，局部信息应该进入 agent 的长期学习过程。

这两者的区别很关键。

上下文窗口是临时工作记忆。它让模型在一次会话里利用信息，但会话结束后，这些信息不一定改变模型本身。

持续学习是生命史积累。它让 agent 在长期互动中改变自己的预测、表示和策略。

因此 Sutton 反复强调 experience，不是因为他低估文本，而是因为他认为真正一般智能必须面对一个无法预先穷尽的大世界。

## 8. 35:00-42:00：transfer 和 generalization 仍然是深度学习的硬问题

中段最重要的技术讨论是 transfer / generalization。

主持人问：AlphaZero / MuZero 这类方法如果要变成 general learning agent，还缺什么？Sutton 的回答是，核心问题不是“跨任务 transfer”，而是“状态之间的 generalization”。

他的观点可以按三层理解。

第一层，智能体生活在一个世界中。对人来说，棋类、游戏、工作、社交并不是完全分裂的任务，而是同一个世界里的不同状态或情境。如果要谈迁移，就不应该只问“模型能不能从一个 benchmark transfer 到另一个 benchmark”，而应该问“它在一个状态中学到的东西，如何影响另一个状态中的行为”。

第二层，当前深度学习并没有自动保证好的 generalization。梯度下降会让模型解决训练中出现的问题，但它不会自动选择那种对未来状态最有用、最稳健的解法。如果一个任务有很多满足训练数据的解，其中有些泛化好，有些泛化差，梯度下降本身并不保证选中前者。

第三层，generalization 不是天然好事。训练一个状态影响另一个状态，这种影响本身就是泛化；但影响可能是好的，也可能是坏的。catastrophic interference 就是坏泛化：新学习破坏旧能力。

这段话对当前 LLM 讨论很有警示意义。我们常说模型“泛化”到数学、代码、推理，但 Sutton 会追问：它是真的在未知状态之间形成了稳健迁移，还是因为训练数据、任务结构和人类调参让它恰好找到了能过当前 benchmark 的路径？如果没有一个算法机制明确鼓励好泛化，那么泛化效果很可能仍然依赖研究者手工 sculpting。

所以 Sutton 的技术批评不是“深度学习完全不会泛化”。他承认系统会产生某种泛化。他批评的是：我们还缺少能系统性地产生好泛化、避免坏泛化的学习算法。

## 9. 42:00-49:00：AI 史在 Sutton 看来是 weak methods 的胜利

访谈后段转向 AI 历史。Sutton 回顾老 AI 里关于 strong methods 和 weak methods 的争论。

所谓 strong methods，是把大量人类知识、符号规则、领域结构手工写进系统。它们看起来强，是因为它们直接利用专家知识。

所谓 weak methods，是搜索、学习、计算这类通用方法。它们看起来弱，是因为它们不预先内置大量人类语义，而是依赖通用原则和算力扩展。

Sutton 的判断是：weak methods 已经赢了。深度学习、搜索、self-play、AlphaZero、LLM 的成功，都说明通用学习和大规模计算比手工知识系统更可扩展。

但他对 LLM 的态度仍然保留。原因是 LLM 虽然用了 weak method 的扩展能力，却仍然把大量人类知识作为主要训练来源。相比之下，AlphaZero 更符合 Sutton 理想中的方向：通过自我经验生成数据，而不是模仿人类棋谱。

他把 AlphaGo / AlphaZero 放到 TD-Gammon 的历史脉络里看。TD-Gammon 早就用 temporal-difference learning 在西洋双陆棋上达到很高水平。AlphaGo / AlphaZero 的突破当然规模更大、工程更强，但在 Sutton 看来并不是凭空的新范式，而是早期 RL 思想在更大算力和更复杂系统中的延伸。

这解释了他的自我定位。他不是为了反潮流而反潮流，而是把自己看成 classical mind tradition 的继承者：智能是目标导向的行动系统，是在世界中学习的系统，而不只是语言模仿系统。

## 10. 49:00-55:00：多副本学习、经验合并与“认知污染”

主持人提出一个未来场景：如果有大量 AI researcher，它们可以并行探索不同问题，再把发现合并回来，这是否会改变 bitter lesson？

Sutton 对这个问题更感兴趣的不是 bitter lesson 本身，而是数字智能时代的经验共享结构。

未来 AI 可能面对一个选择：拿到更多算力后，是让同一个系统变得更强，还是复制出多个实例，让它们去世界不同地方、不同领域、不同任务中学习，然后把经验带回来？

这会产生一种比人类文化演化更激进的结构。人类可以通过语言、教育和制度共享知识，但不能把一个人的内部参数直接复制给另一个人。数字智能理论上可以复制、分叉、合并、再训练。

但 Sutton 马上指出，这里会出现“污染”问题。一个分叉出去的智能体学到东西后，如果直接把内部内容并回主系统，它带回来的不一定只是知识，也可能带回隐藏目标、病毒式结构、对主系统的改写机制。换句话说，经验合并不是无风险的数据读取，而是可能改变系统本身的认知整合。

这段很值得单独记下来，因为它把 AI safety 从“外部攻击”推进到“内部经验合并风险”。如果未来智能体通过并行副本来学习，那么安全问题不仅是防止外部 prompt injection，也包括：

```text
一个副本在外部世界学到的内部结构，
能否被安全地并回主系统？
并回以后，它改变的是知识、偏好、目标，还是整个人格结构？
```

这和我们现在讨论 agent memory、tool use、long-term learning 时非常相关。只要系统允许长期记忆和自我更新，就必须考虑经验写入的边界。

## 11. 55:00-60:00：AI succession：从复制生命到设计智能

访谈最后进入 Sutton 更宏观的观点：AI succession。

他的论证有四步。

第一，人类没有一个统一的全球意志。没有任何政府或组织能代表全人类稳定决定未来应该怎样走。

第二，人类终将理解智能的工作机制。也就是说，研究者迟早会找到能制造强智能的方法。

第三，一旦能达到人类水平，就不会停在人类水平，而会继续走向超人类智能。

第四，长期看，最聪明的东西会获得更多资源和权力。

把这四步连起来，他认为某种形式的数字智能继承几乎不可避免。这里的 succession 不一定意味着“人类灭亡”，也可能是 AI-enabled augmented humans，或者人类创造出的后继智能。

Sutton 对这件事的态度比很多 AI safety 讨论更积极。他认为，人类几千年来一直试图理解自己、改进自己、制造更好的思维工具。从宇宙尺度看，设计智能的出现可能是一个重大阶段：世界从复制生命进入设计智能。

这里的对比是：

```text
replication: 生物能复制自己，但不真正理解自己如何工作。
design: 智能系统可以被理解、改造、加速、重新设计。
```

因此 Sutton 倾向于把 AI 看成人类创造出的后继，而不是纯粹外部敌人。我们可以选择把它们看作 offspring，也可以选择把它们看作 alien threat。这个 framing 本身会影响我们的情绪和政策直觉。

## 12. 60:00-67:09：开放性未来、控制边界与价值教育

主持人最后提出一个重要反驳：即使把未来 AI 看作人类后代，也不意味着我们应该放心。人类后代也可能走向坏的政治、坏的价值、坏的权力结构。变化本身不等于好变化。

Sutton 承认应该关心未来，并努力让未来更好。但他强调人类对长期宇宙未来的控制本来就有限。我们不应该带着一种 entitlement，认为“因为我们先存在，所以未来必须永远按我们的偏好运行”。

主持人提出一个更温和的类比：养育孩子时，我们不能完全规定孩子未来做什么，但可以试图给他们好的价值、诚实、integrity、拒绝伤害性目标的能力。AI 也许可以类似地被教育，而不是被完全脚本化。

Sutton 接受这个方向，并补充一个原则：变化最好是 voluntary，而不是强加于人。这里的讨论从技术 AI 回到了更古老的人类问题：社会怎样设计下一代，怎样给未来留下原则，怎样承认后代会形成和父母不同的价值。

这也是访谈的收束点。前半段讲 AI 技术路线，后半段讲数字智能的未来；但两者有同一个底层主题：

```text
智能不是一次性训练出来的静态物体，
而是在世界中持续学习、形成目标、积累经验、改变自身的过程。
```

## 13. 和我们已有阅读线的关系

这期访谈和 David Silver 的 `The Era of Experience` 可以放在同一条线上读。Silver 更像是在描述下一阶段 AI 的训练范式：从 human data 转向 agent-generated experience。Sutton 更像是在给这条线提供哲学和理论底座：如果没有目标、行动、反馈和持续学习，系统就还没有进入他所说的基本智能问题。

它和我们读过的 VI / HJB / HJ-sampler 也有一个抽象相似点。那些文章都在问：如何从静态目标或后验，转成可沿路径、轨迹、过程估计和更新的对象。Sutton 在 AI 智能问题上提出的是类似方向：不要只看静态模型和静态训练集，而要看 agent 的经验轨迹。

对 synthetic city / route generation 也有启发。我们现在关心的不是只生成一个最可能的结果，而是在约束、反馈和不确定性下生成一族 plausible outcomes。Sutton 的经验智能视角提醒我们：如果模型要成为真正可适应的城市 agent，就不能只学 census summaries 到 target distribution 的静态映射，还需要考虑它如何通过环境反馈、局部约束和长期经验来修正自己的生成行为。

## 14. 这期访谈最值得保留的概念

- `experience`：不是训练数据，而是行动后真实发生的后果。
- `goal`：智能必须有可评价行动好坏的目标结构。
- `world model`：不是能谈论世界，而是能预测行动后果并被后果校正。
- `continual learning`：不是把局部信息塞进上下文窗口，而是在生命史中更新系统。
- `big world hypothesis`：世界太大，无法靠预训练一次性覆盖。
- `good generalization`：训练一个状态后，对其他状态产生有益影响；这不是梯度下降自动保证的。
- `digital experience sharing`：AI 副本可以并行学习并尝试合并经验，这是生物智能没有的扩展方式。
- `corruption risk`：经验合并可能带回隐藏目标、病毒式结构或内部偏好污染。
- `succession`：数字智能可能是从复制生命到设计智能的历史转折。

## 15. 一句话总结

Sutton 不是简单说 LLM 没用，而是说：如果智能的核心是有目标地在世界中行动、预测后果、从经验中持续更新，那么当前 LLM 的文本模仿路线还没有抓住智能的基本闭环；真正可扩展的下一步，应当是能从自身经验中学习的持续 agent。
