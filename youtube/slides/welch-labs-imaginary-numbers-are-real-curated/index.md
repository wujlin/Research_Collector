# Welch Labs: Imaginary Numbers Are Real - Curated Frames

This directory contains a series-level curated frame set for the integrated complex-numbers note.

- `frames/`: 24 representative frames selected from the 13-video series.
- `contact_sheet.jpg`: visual index for the curated frame set.
- `contact_sheets/`: raw contact sheets for each video part, used for frame selection.

The curated sequence follows the conceptual line:

1. no real solution and the need to extend number systems;
2. historical pressure from cubic equations;
3. `sqrt(-1)` as an algebraic object;
4. complex numbers as two-dimensional numbers;
5. complex multiplication as rotation and scaling;
6. algebraic closure;
7. complex functions as plane-to-plane maps;
8. Riemann surfaces as a way to organize multi-valued complex functions.
